# Знак и логотип UnPlugged

**Знак — пиксельная сетка 3×3**, слово «nPlugged» — обычным шрифтом (Onest, weight 700), переведённым
в кривые. Контраст в логотипе даёт не вторая пиксельная азбука, а «пиксельный знак против гладкого
слова»: знак читается как вынутая из розетки деталь, слово — как нормальная подпись.

| Файл | Когда брать |
| --- | --- |
| `logo.svg` | основной логотип на **тёмном** фоне (лобби, сайт, тёмная тема) |
| `logo-on-light.svg` | тот же логотип на светлом фоне: три цвета на ступень темнее, иначе голубой на белом слепнет |
| `logo-mono.svg` | одноцветный логотип: печать, штамп, вышивка, водяной знак |
| `logo-stacked.svg` | квадратная раскладка: знак сверху, слово под ним (аватар, обложка, соцсети) |
| `mark.svg` | знак с улетевшими квадратами — крупный размер, от ~48 px |
| `mark-mono.svg` | знак в один цвет |

Иконки лежат в корне `public/` — там, откуда их берёт браузер (`nuxt.config.ts`, `public/manifest.json`):

| Файл | Что это |
| --- | --- |
| `favicon.svg` | знак **с крупным улетевшим квадратом** («точка» вверху): он читается и в 16 px, а мелкий квадрат — нет, поэтому в иконку не идёт |
| `favicon.ico` | то же в 16/32/48 px (записи PNG внутри ICO) |
| `favicon-180.png` | иконка домашнего экрана iOS, на подложке `--color-app` |
| `favicon-192.png`, `favicon-512.png` | иконки приложения |
| `icon-192.png`, `icon-512.png` | они же с запасом под круглую маску (`purpose: maskable`), на них ссылается манифест |

Правила, по которым всё собрано:

- **Знак — первая буква слова.** В локапе улетевший **мелкий** квадрат убран: он попадал в x-height
  первой буквы. Крупный остаётся и в локапе, и в иконке — он и говорит «отключено».
- **Высота знака равна высоте заглавной буквы слова** (`--mark-scale=1`): знак и заглавные одной высоты.
- **Просвет до слова** — `--gap=0.1` от высоты заглавной, и считается он **от правого края буквы U**,
  а не от улетевшего квадрата (квадрат висит выше линии заглавных и в просвет не вмешивается).
  Больше — просторнее (`--gap=0.22` было в первой версии), меньше 0.05 — слово уже липнет к знаку.
  Варианты сравнения — `.workbuddy/logo-preview/gap-compare.png`.
- **Градиент один на весь логотип:** знак идёт `cyan #22D3EE` → `violet #8B5CF6`, слово продолжает
  `violet` → `pink #D946EF`. Одной полосой, а не двумя радугами. Цвета — `docs/ui-plan.md` §9.2.
- **Слово в кривых.** SVG не должен зависеть от того, установлен ли шрифт у того, кто его откроет:
  иначе в Illustrator/Figma/на печати буквы подменятся запасным — это и есть «качество страдает».
- **Монохром залит `currentColor`.** Инлайном в HTML он берёт цвет текста; как `<img>` — рисуется
  чёрным, поэтому для картинки подставьте `fill` сами.

## Шрифт слова

По умолчанию — **Onest, weight 700**, трекинг −0.01 em. Файл шрифта и его лицензия лежат в
репозитории (`tests/support/fonts/Onest-700.ttf`, `Onest-OFL.txt`): логотип не обязан совпадать со
шрифтом интерфейса, а сборка не должна зависеть от сети и от того, что оказалось в `node_modules`.
Любая другая гарнитура подставляется ключом `--font`:

```powershell
python tests/support/bake-wordmark.py --font=tests/support/fonts/Poppins-700.ttf --label=Poppins
```

Что уже смотрели на этом знаке — **30 семейств Google Fonts**, все свободные (OFL или Apache 2.0,
то есть годятся и для коммерческого логотипа, и для печати): Archivo, Baloo 2, Bricolage Grotesque,
Chivo, Comfortaa, DM Sans, Exo 2, Figtree, Fredoka, Golos Text, Inter, Karla, Lexend, Manrope, Michroma,
Montserrat, Nunito, Onest, Outfit, Plus Jakarta Sans, Poppins, Red Hat Display, Rubik, Russo One, Sora,
Space Grotesk, Unbounded, Urbanist, Wix Madefor Display, Work Sans. Листы-образцы — в
`.workbuddy/logo-preview/specimen-{1,2,3}.png`.

Остановились на Onest (решение владельца). Если меняете гарнитуру, положите новый файл и его лицензию
рядом — тогда сборка логотипа остаётся воспроизводимой без сети.

## Прошлая версия

`legacy/` — прежний знак: скруглённая буква U с облаком пикселей и слово Manrope в кривых
(`legacy/logo*.svg`, `legacy/mark*.svg`, старые фавиконки `legacy/favicon-u.svg`, `legacy/favicon-u.ico`).
Оставлен намеренно, не удалять: собирается `tests/support/bake-logo.py`.

## Пересборка

```powershell
python tests/support/bake-wordmark.py   # логотип: знак + слово в кривых → app/svg/brand/logo*.svg
node tests/support/bake-brand.mjs       # знак и все иконки → app/svg/brand/mark*.svg, public/favicon*, icon-*.png
python tests/support/bake-logo.py       # прошлая версия в legacy/ (нужны fontTools, brotli, uharfbuzz)
```

В приложении: `app/components/molecules/Logo.vue` показывает `logo.svg` компонентом (`vite-svg-loader`),
поэтому правки в `app/svg/brand` видны в лобби сразу. Источник правды — бейкеры, а не файлы.
