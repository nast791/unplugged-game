# Оси героев: что бот должен видеть у каждого пака

Инвентарь условий **всех шести паков** (`server/content/heroes/*/index.js` и `cards.js`): какие свойства
карт зависят от состояния и как это состояние читается фактами движка. Из него выросли условная
ценность карт (`bot/play/cards.js: cardPromise`, §20) и признаки оценки (`bot/play/value.js`, §20).

Как читать столбец «в боте»:

| пометка | что значит |
| --- | --- |
| **оценка** | признак считается в `bot/play/value.js` (веса обучаются) |
| **политика** | ценность карты считается в решении (`cardPromise`, политика `conditions`) |
| **нет** | состояние бот не видит или не оплачивает; строка-кандидат в работу |

## Анубис (`anubis`)

| ось | что даёт | чем читается | в боте |
| --- | --- | --- | --- |
| Покой | `anubis_01` — значение 6 вместо 4; `anubis_09` — добор и лечение; умение `turnEnd` — 1 урон, 2 с пеленой | `FIGHTERS { fighterIds: ['anubis'], movedThisTurn: true }, max: 0` | политика + оценка (`stillness`) |
| Пелена | усиливает суд (2 вместо 1) и рвётся в начале хода вне пустыни | `ITEMS { group: 'shroud', state: 'active' }` | оценка (`resourceOn`), политика — только как вариант свойства |
| Пустыня | `anubis_07` — значение 4; пелена держится только на песке; `anubis_02` — +1 урон по врагу на песке | `FIGHTERS { …, terrain: 'desert' }` | политика (обе карты), шаг на свою стихию — ген `terrain` |
| Чужая рука | `anubis_03` — сброс карты при руке ≥ 4; `anubis_06` — добор при пустой руке | `HAND { of: '$enemy', min: 4 / max: 0 }` | политика (обе), оценка (`rivalHand` — размер руки) |
| Зеркало и подмена | `anubis_04` — значение равно усилению чужой атаки; `anubis_14` — защитник перекладывает защиту | `COMBAT { bonus: 'opponent' }`, `SET_COMBAT { op: 'replaceDefense' }` | **нет** для `anubis_04` (чужая карта до вскрытия скрыта — честно не читаем), `anubis_14` работает движком |
| Амат | `anubis_08` — шаг равен усилению верха своей колоды; `anubis_10` — добор 2 за смерть зверя; `anubis_13`/`_14` играются только при живом звере | `REVEALED { of: 'self', select: 'bonus' }`, `LOST { type: 'assistant' }` | оценка (`sidekickHp`), политика — `LOST` через `cardPromise` (`anubis_10` — момент `effect`, не входит) |

## Дороти (`dorothy`)

| ось | что даёт | чем читается | в боте |
| --- | --- | --- | --- |
| Развод с Тото | `dorothy_01` — 3→5, когда Дороти **не** в одной области с Тото; при мёртвом Тото условие тоже истинно (`areaOf` без ориентира даёт пустой список, `max: 0` проходит) | `FIGHTERS { fighterIds: ['dorothy'], areaOf: 'toto' }, max: 0` | политика |
| Неподвижность | `dorothy_08` — 3→5, если не перемещалась | `FIGHTERS { fighterIds: ['dorothy'], movedThisTurn: false }, min: 1` | политика + оценка |
| Широкая рука | `dorothy_06` — 3→5 при руке ≥ 4 | `HAND { min: 4 }` (своя) | политика |
| Стихия и тип цели | `dorothy_02` — +1 по цели на лаве или пустыне; `dorothy_05` — +1 против героя | `FIGHTERS { fighterIds: '$foe', terrain }`, `… type: 'hero'` | политика (обе) |
| Плотность своих | `dorothy_03` — 3→5, когда рядом свой боец или союзник; `dorothy_11` несёт пару вместе | `FIGHTERS { side: 'self'/'teammate', adjacentTo }` | политика (`dorothy_03`), `dorothy_11` — движение |
| Победа как темп | `dorothy_07` — +1 действие и сдвиг Тото; при мёртвом Тото карта гаснет | `COMBAT { winner: 'self' }` + `FIGHTERS { group: 'toto' }` | **нет** (исход боя не обещаем — решение принимается до него) |
| Обмен местами | умение `turnEnd`: окно по паре, `SWAP_FIGHTERS`, телепорт не ломает покой | `FIGHTERS { …, areaOf: 'dorothy' }, min: 2` | движок открывает окно, бот выбирает вариант |

## Ифрит (`ifrit`)

| ось | что даёт | чем читается | в боте |
| --- | --- | --- | --- |
| Число духов | `ifrit_06` — +2 / +1 / добор при 3 / 2 / 1 духе; `ifrit_11` — бюджет шага 3/2/1 сквозь врагов; умение — дух за действие | `FIGHTERS { side: 'self', group: 'ash', min, max }` | оценка (`sidekickHp`, `fighters`), политика |
| Стихия | `ifrit_02` — лава +2, пустыня +1 (**складываются** на двухцветной клетке); `ifrit_03` — карта возвращается в руку с лавы; `ifrit_10` — прыжок на лаву | `FIGHTERS { fighterIds: ['ifrit'], terrain }`, `CELLS { terrain: 'lava', free: true }` | политика (`ifrit_02`), шаг на стихию — ген `terrain` |
| Номер действия | `ifrit_13`: 1-е действие — добить в области Ифрита, 2-е — +2, если двигался, 3-е — отмена свойств чужой карты | `AP { spentMin, spentMax }` | **нет** (обещанная польза считается до боя, а `AP` в `cardPromise` не читается) |
| Топливо колоды | `ifrit_05` — +2 за сброс верха колоды (пустая колода — без прибавки) | `DECK { min: 1 }` | политика |
| Роль в бою | `ifrit_13` в защиту режет число чужой карты на 1 | `COMBAT { role: 'defender' }` | политика (в открытом бою) |
| Смерть духа | `ifrit_04` — сжечь своего духа за +1 к числу боя | `FIGHTERS { group: 'ash' }` + `SET_TARGETING` | движок открывает окно, вариант оценивается (`optionWorth`) |

## Медуза (`medusa`)

| ось | что даёт | чем читается | в боте |
| --- | --- | --- | --- |
| Победа в бою | `medusa_01` — +8 урона атакованному; `medusa_09` — добор 2 вместо 1 | `COMBAT { winner: 'attacker' / 'self' }` | **нет** (исход боя до боя не обещаем) |
| Пустая рука врага | `medusa_03`, `medusa_05` — сброс карты врага; при пустой руке свойства нет | `HAND { of: '$enemy', min: 1 }` | политика (обе), оценка (`rivalHand`) |
| Отмена свойств | `medusa_08` — свойства чужой карты не действуют (числа не меняет) | `COMBAT { effects: 'opponent' }, min: 1` | **нет** (свойства боя до вскрытия не обещаем) |
| Внебоевой урон | `medusa_10` — 2 урона бойцу в области Медузы (окно обязательное); умение `turnStart` — 1 урон каждый ход без окна | `FIGHTERS { areaOf: 'medusa' }` | политика (урон в `picked`), движок бьёт сам |
| Гарпии | `medusa_04` — движение трёх; `medusa_05` — сброс карты; `medusa_11` — возрождение | `FIGHTERS { group: 'harpies' }`, `LOST { group: 'harpies' }` | оценка (`sidekickHp`), политика |
| Дальность | герой `attackRange: 3`, гарпии — 1 | паспорт пака | ген `stepAway`/`hold` (кайт), `terrain` у неё нулевой |

## Снежная королева (`snow-queen`)

| ось | что даёт | чем читается | в боте |
| --- | --- | --- | --- |
| Осколки в своём сбросе | пороги: 4 — заморозка (`_02`), 5 — отмена свойств (`_10`), 6 — 2 урона (`_12`) и лимит руки врагов (умение), 8 — +1 урон (`_02`), 9 — значение 7 (`_06`) | `CARDS { zone: 'discard', tag: 'shard', min }` | оценка (`resource`, порог 6 из умения), политика — только порог 6; **ступени 4/5/8/9 не в решении** |
| Лимит руки врагов | 6+ осколков → лимит руки врагов 5 вместо 7 | `SET_HAND_LIMIT { of: 'enemies' }` | **нет** (в оценке жёсткая 7) |
| Контроль в бою | `_02` — заморозка атакующего; `_10` — отмена свойств; `_01`/`_03` — выбивание карты из руки | `SET_STATUS { frozen }`, `COMBAT { effects }`, `HAND { of: '$enemy' }` | заморозка — оценка (`frozen`); отмена и выбивание — политика/движок |
| Лёд | `_06` — 4 стоящему на льду; `_01` — телепорт чужого бойца на свободный лёд; `_13` — возврат вороны на лёд | `FIGHTERS { …, terrain: 'ice' }`, `CELLS { terrain: 'ice', free: true }` | политика (`_06`), шаг на стихию — ген `terrain` (`terrainAffinity: ['ice']`) |
| Просадка ресурса | `_12` замешивает 3 осколка из сброса в колоду — счётчик падает, пороги отключаются | `SET_CARDS { op: 'move', from: 'discard', to: 'deck' }` | **нет** (цена карты не видна) |
| Осколки без боя | гибель вороны сбрасывает верхнюю карту колоды (может дать осколок) | `DEATH { group: 'crow' }` + `DECK { min: 1 }` | движок, оценка (`sidekickHp`) |
| Колода неполная | 22 карты из 30 | — | видно в матрице: покрытие 9/9, винрейт 19–20% |

## Тесла (`tesla`)

| ось | что даёт | чем читается | в боте |
| --- | --- | --- | --- |
| Катушки (порог «обе») | умение `turnStart`: 1 урон всем врагам рядом с Теслой и толчок на 1 | `ITEMS { group: 'coil', state: 'active' }, min: 2` | оценка (`resourceOn`, порог 2 из умения) |
| Катушки как цена числа | `tesla_03` — атака становится 5 (1 катушка) или 7 (2) | `options[].when` + `SET_COMBAT { op: 'value', side: 'attack', to }` | **нет** (лежит в варианте свойства, а не в карте) |
| Катушки как цена ресурсов | `_02` — действие, `_04` — добор и лечение, `_06` — урон по области, `_07` — отмена свойств и обнуление числа, `_08` — движение и сброс карты врага | `SET_ITEM` + `options` | `optionWorth` (польза и цена), оценка (`resource`) |
| Восстановление | `_01` `charge` — обе; `_09` — 1 за карту, обе при победе; `_11` — обе и действие | `SET_ITEM { to: 'active' }` | `optionWorth`; обещание карты (`_09` — первое правило) |
| Чужая колода | `_05` — число карты растёт на бонус раскрытой верхней карты противника | `REVEALED { of: '$enemy', select: 'bonus' }` | **нет** (в `optionWorth` подстановка `$bonus` даёт 0) |
| Дальность | герой `attackRange: 3` | паспорт пака | ген `stepAway`/`hold`; `terrainAffinity` нет |

## Что осталось невидимым (осознанно или как задача)

| пробел | герои | почему / что нужно |
| --- | --- | --- |
| Ступени-пороги (4/5/8/9 осколков, 5/7 у Теслы) | Снежная королева, Тесла | нужен признак «расстояние до ближайшей ступени карты», а не только до порога умения |
| Исход боя и отмена свойств | Медуза, Анубис, Дороти, Снежная королева | обещание считается **до** боя: `winner`, `bonus`, `effects` не читаем — иначе подглядывание |
| Номер действия (`AP spent`) | Ифрит (`_13`) | ценность зависит от того, каким по счёту действием играется карта |
| Лимит руки врагов | Снежная королева | в оценке жёсткая 7 (`handLimit`), умение ставит 5 |
| Чужая рука (состав) | Медуза, Снежная королева, Анубис | `HAND { of: '$enemy' }` читает только счёт и метки — это открытый счётчик; состав карт скрыт проекцией |
| Чужие предметы и потери | все | у фактов `ITEMS` и `LOST` нет параметра `of` |
| Условия карт в эталонах | все | их оплачивает ген `condition` (политика `conditions`); `greedy` и замороженные эталоны играют по напечатанному числу |
