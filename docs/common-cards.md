# Библиотека общих карт

Общая часть колоды: карты, которые в референсах встречаются у многих героев под одним и тем же
названием и с одним и тем же текстом. Задача библиотеки — ускорить выпуск героев, дать игроку
узнаваемый «общий язык» колод и держать мету: часть ответов на архетипы есть у всех.

Связанные документы: `docs/card-capabilities.md` (словарь возможностей и покрытие движка),
`docs/hero-balance.md` (бюджет героя), `docs/reference-heroes.md` (разбор референсов).

**Как считали.** В `.refs/` лежат сканы карт 64 героев (814 картинок). Названия прочитаны

делаем из четырёх ролей, а остальное — наши добавки под архетипы.

### Частота приёмов (что вообще имеет смысл делать общим)

Оценка по тексту разборов (`docs/reference-heroes.md`, 64 героя): отмена эффектов — у большинства;
добор и награда за бой — 52 героя; дополнительное действие — около 50; лечение — 44;
принудительный сброс карты — 41; усиление карты картой — 35; игра через область — 34;
телепорт — 27; самоповреждение как цена — 24; проход сквозь врагов — 22.

Наша четвёрка базовых карт ровно и закрывает самое частое: контр-игру (отмена), экономику (добор),
бой (условное значение) и позицию (сдвиг после боя).

## 2. Как устроена общая часть

| Параметр                  | Значение                                                                |
| ------------------------- | ----------------------------------------------------------------------- |
| Колода                    | 30 карт                                                                 |
| Порядок работы            | **сначала уникальные механики и карты героя, потом добор общими до 30** |
| Сколько общих берёт герой | **сколько нужно**: от нуля до всех четырёх                              |
| Копии общих               | **1–3 на карту**, не больше трёх                                        |
| Значения общих            | атака/защита не выше 4, boost 1–2, прямой урон не больше 2              |
| Привязка                  | нет: карту без привязки может играть любой боец                         |

Правила выбора:

1. **Общие карты — балансировочный остаток, а не обязательная программа.** Сначала герой
   собирается своими картами, общими добирается до 30.
2. **Не все четыре карты обязаны быть у героя.** Нет нужды в доборе — «Паузу» не берём.
3. **Копии подбираются по нужде:** 1, 2 или 3. Три — только если карта нужна герою постоянно;
   у уникальных карт героя правило то же: больше трёх копий не бывает.
4. **Общие карты не повторяют приём героя.** Есть у героя перемещение как фишка — «Отход» он
   не берёт, берёт что-то из другой роли.
5. **Ответы на архетипы распределены по пулу**: у меты не должно быть непробиваемой стратегии.
6. **Числа общих не повторяют оригинал.** Проверка сканов (`.refs/_stats/*.csv`) показала: у одной
   и той же роли в разных наборах числа разные, и наши прежние попадали в эти наборы — «Обманный
   маневр» 2/2 повторял «Уловку», «Пауза» 1/2 — «Передышку». Для «Паузы», «Отхода» и «Разбега» числа
   выведены за пределы наблюдавшихся; у «Обманного маневра» владелец выбрал 2/1 — совпадение с самой
   частой сигнатурой отмены в сканах, см. §3.

**Три из четырёх уже есть у Медузы** — «Обманный маневр» (`medusa_08`), «Второе дыхание»
(`medusa_09`) и «Ядовитая стрела» (`medusa_07`, добор после боя), все три без привязки к бойцу.
Когда соберём первого героя с общей частью, эти карты переезжают в библиотеку, а колода Медузы
начинает брать их оттуда: держать их в двух местах нельзя. Числа этих карт в контенте Медузы ещё
старые («Обманный маневр» 2/2) — приводим к §3 в тот же проход.

## 3. Наши четыре базовые карты

Формулировки, названия и числа — наши. Из оригинала взята только **роль** карты (отмена эффектов,
добор после боя, условное значение, сдвиг после победы): это механика, она не охраняется.

Готовый файл: `server/content/common/cards.js`. Колода героя берёт общие карты его же хелпером:
`import { commonCard } from '../../common/cards.js'` → `commonCard('common_feint', 2)` — карта приходит
из пула целиком, герой задаёт только число копий (см. `server/content/heroes/dorothy/cards.js`).

| id                 | Название        | Тип    | Знач. | Boost | Копий | Текст (наш)                                                                                  |
| ------------------ | --------------- | ------ | ----- | ----- | ----- | -------------------------------------------------------------------------------------------- |
| `common_feint`     | Обманный маневр | гибрид | 2     | 1     | до 2  | МГНОВЕННО: Свойства карты оппонента в этой битве не действуют.                               |
| `common_breather`  | Пауза           | гибрид | 2     | 2     | до 2  | ПОСЛЕ БИТВЫ: Доберите карту. В случае вашей победы доберите две.                             |
| `common_fall_back` | Отход           | гибрид | 3     | 1     | до 2  | ПОСЛЕ БИТВЫ: Если вы победили, ваш боец, участвовавший в битве, может пройти до двух клеток. |
| `common_spurt`     | Разбег          | атака  | 4     | 1     | до 2  | ВО ВРЕМЯ БИТВЫ: Если ваш боец в этом ходу перемещался, значение карты +2.                    |

**Проверка чисел (сделана заново).** Числа сверены со сканами: в `.refs/_stats/*.csv` на каждую карту
записаны тип, значение, усиление и множитель копий. Роли, которые повторяются у десятков героев,
выглядят так: отмена эффектов — 2/1 и 2/2, добор с наградой за победу — 1/2 и 1/1, сдвиг после
победы — 4/1, 4/2 и 3/2, условное значение за перемещение — 3/1. Прежние наши числа (2/2, 1/2, 2/1,
3/1) попадали в эти наборы, то есть повторяли чужие. Итог: «Пауза» 2/2, «Отход» 3/1, «Разбег» 4/1 —
вне наблюдавшихся наборов; «Обманный маневр» 2/1 — по решению владельца, и это как раз самая частая
сигнатура отмены (20 колод из 64), то есть совпадение сознательное. Свободны от совпадений у отмены
1/1 и 1/2. Названий в CSV нет, поэтому для «Стычки» и «Переломного момента» роль определена по флагам
механик и по частоте роли среди героев, а не по имени карты: если понадобится, сверим сканы глазами.

**Про «Отступление».** Такое название в референсах занято: «ОТСТУПЛЕНИЕ» есть у Бигфута
(«ПОСЛЕ БОЯ: Выберите пустую…»), а «РАЗРЫВ» — у Геральта. Поэтому взял «Отход»: в референсах
такого названия нет. Если хочется другого — свободны «Откат» и «Шаг назад».

**Одна оговорка по движку.** «Разбег» требует помнить, что боец **в этом ходу перемещался**: флаг
`movedThisTurn` ставит `SET_FIGHTER_CELL` при шаге и снимает начало хода
(`shared/lifecycle/turnStart.js`), факт читает его как `FIGHTERS { movedThisTurn: true }`. Тот же флаг
с обратным условием использует карта Дороти «Наотмашь» (`server/content/heroes/dorothy/passport.md` §7).

## 4. Наши инструменты (добавляем сами)

Этих карт в оригинале нет — они наши ответы на архетипы, которые мы видим в своих героях.
Герой берёт их **вместо** базовой карты той же роли.

| id              | Название       | Тип    | Знач. | Boost | Текст (наш)                                                      | На что отвечает                  |
| --------------- | -------------- | ------ | ----- | ----- | ---------------------------------------------------------------- | -------------------------------- |
| `common_jab`    | Удар в упор    | атака  | 3     | 1     | без свойств                                                      | простой «хлеб» для слабых героев |
| `common_guard`  | Глухая защита  | защита | 3     | 1     | без свойств                                                      | то же, для обороны               |
| `common_shove`  | Толчок         | защита | 2     | 1     | ПОСЛЕ БОЯ: сдвиньте атакующего на 1 клетку от вашего бойца.      | дальний бой и кайтинг            |
| `common_grab`   | Ограбление     | атака  | 2     | 1     | ПОСЛЕ БОЯ: противник сбрасывает 1 карту.                         | козырь в руке                    |
| `common_mend`   | Перевязка      | эффект | —     | —     | Восстановите 2 здоровья вашему герою.                            | затяжная игра                    |
| `common_recall` | Подмога        | эффект | —     | —     | Верните убитого помощника в область вашего героя.                | потеря помощников                |
| `common_second` | Второе дыхание | эффект | —     | —     | Получите дополнительное действие, затем получите 1 урон.         | темп за цену                     |
| `common_volley` | Залп           | атака  | 2     | 2     | ПОСЛЕ БОЯ: 1 урон всем бойцам противника в области вашего бойца. | толпа помощников                 |

Все карты библиотеки реализуются текущими средствами движка (`docs/card-capabilities.md` §2):
`SET_HEALTH`, `SET_CARDS`, `SET_MOVEMENT` (умеет и врагов), `SET_ACTIONS`,
`SET_COMBAT { op: 'value' | 'cancelEffects' }`, факты `FIGHTERS { side, type, areaOf, adjacentTo,
movedThisTurn, min, max }`, `LOST { type }`, `REVIVE_FIGHTER { groups }`. «Разбег» работает от флага
«боец двигался в этом ходу» — флаг уже есть (оговорка в §3).

**Одна тонкость про значения фактов.** `FIGHTERS` отдаёт список объектов, `COMBAT { select }` — список
id, а параметры `areaOf`, `adjacentTo` и `fighterIds` ждут одного бойца. Такое значение разбирает
`findFighter`: принимает и строку, и элемент списка, и объект `{ fighterId }` — поэтому
`CELLS { areaOf: '$heroes' }` в «Подмоге» и `FIGHTERS { of: '$enemy' }` в картах читаются одинаково.
Отдельно: `COMBAT { select }` **во время битвы** читает открытый бой, а не только итог, — иначе свойства
«во время битвы» не видели бойцов (итог сбрасывается объявлением атаки).

**Почему «Залп» бьёт по своей области, а не по области цели.** В области цели он читался бы честнее,
но цель часто погибает в бою: у убитого бойца `currentPosition` обнуляется и уходит в `player.lost`,
поэтому его клетку уже не найти — карта молчала бы ровно там, где нужна (снять рой вокруг добитой
цели). Свой боец после боя на поле и его область известна; роль «ответ на толпу помощников» при этом
та же.

### Как это выглядит в файле

Четыре базовые карты уже лежат в `server/content/common/cards.js` в том же формате, что колоды
героев (`id`, `title`, `type`, `value`, `bonus`, `quantity`, `text`, `rules`). Пример оттуда:

```js
{
  id: 'common_fall_back',
  title: 'Отход',
  type: 'hybrid',
  value: 3,
  bonus: 1,
  quantity: 2,
  text: 'ПОСЛЕ БИТВЫ: Если вы победили, ваш боец, участвовавший в битве, может пройти до двух клеток.',
  rules: [
    {
      moment: 'afterCombat',
      when: [
        { fact: 'COMBAT', params: { winner: 'self' } },
        // двигается тот, кто играл карту: у атакующего — атакующий, у защитника — тот, кого били
        { fact: 'COMBAT', params: { select: 'self' }, var: 'fighters' },
      ],
      then: [
        { action: 'SET_MOVEMENT', op: 'open', budget: 2, fighters: '$fighters', optional: true },
      ],
    },
  ],
}
```

Привязки к бойцу у общих карт нет — движок считает карту без привязки доступной всегда
(`hasFighterForCard`), а свои бойцы в правилах выбираются фактом `FIGHTERS { side: 'self' }`.
Поэтому одна и та же карта работает у любого героя без правок.

### Ещё два примера из библиотеки (инструменты)

```js
// Второе дыхание: дополнительное действие за 1 урон
{
  id: 'common_second',
  type: 'effect',
  text: 'Получите дополнительное действие, затем получите 1 урон.',
  rules: [
    {
      moment: 'effect',
      then: [
        { action: 'SET_ACTIONS', fighter: 'hero', delta: 1 },
        { action: 'SET_HEALTH', fighter: 'hero', delta: -1 },
      ],
    },
  ],
}

// Подмога: вернуть убитого помощника в область героя
{
  id: 'common_recall',
  type: 'effect',
  text: 'Верните убитого помощника в область вашего героя.',
  rules: [{ moment: 'effect', then: [{ action: 'REVIVE_FIGHTER', areaOf: 'hero' }] }],
}
```

(Точные имена полей сверим с `shared/actions/` при реализации — здесь смысл, а не финальный синтаксис.)

## 5. Что оставляем геройским

В общие карты **не** попадает всё, что делает героя узнаваемым:

- счётчики и жетоны (ярость, пепел, метки);
- смена режима и формы;
- работа с чужой сыгранной картой и её значением;
- призыв новых бойцов и токены;
- карты, читающие стихию: 2–4 карты на героя по нашему правилу;
- «козыри»: значения 5–6, уникальные условия, разовые эффекты.
