# Словарь возможностей карт

Рабочий справочник для проектирования колод: какие вообще бывают эффекты, как они комбинируются и что из
этого наш движок уже умеет. Составлен по публичным правилам и разборам жанра (структура колод и типы
эффектов — это механика, она не охраняется), **без переноса чужих текстов, названий карт и флавора**:
формулировки, названия и числа у нас свои.

Внешние источники (структура и термины, не тексты карт):

- правила системы: [Unmatched System rulebook](https://iellogames.com/wp-content/uploads/2023/06/Unmatched-HvsG_Rulebook_EN_Light.pdf),
  [Unmatched Adventures core rules](https://iellogames.com/wp-content/uploads/2024/02/UN-Adventures_Core-rules_EN_Light.pdf),
  русская книга правил: [gaga.ru](https://gaga.ru/gaga/files/pdf/rules/ru/6352.pdf);
- разбор структуры колод: [Unmatched Deck Structure](https://www.geektopiagames.com/unmatched/unmatched-deck-structure/);
- термины: [The Unmatched Club — Glossary](https://www.the-unmatched.club/rules/glossary).

## 1. Структура колоды (ориентир жанра)

| Параметр           | Ориентир                                                         | У нас сейчас                       |
| ------------------ | ---------------------------------------------------------------- | ---------------------------------- |
| Размер колоды      | 30 карт                                                          | 30 карт                            |
| Деление            | ~18 «особых» (герой и помощники) + 12 общих                      | 11 уникальных геройских, общих нет |
| Общие карты        | одинаковые для многих колод, без привязки к бойцу, значения ниже | отсутствуют                        |
| «Путь к победе»    | 4–6 сильных карт, вокруг которых строится игра                   | у каждого героя свои               |
| «Хлеб»             | 3–4 карты, обычно по 3 копии                                     | у нас три карты по 2 и восемь по 3 |
| Значения           | атака до 6 без штрафов, защита до 4                              | 1–5                                |
| Прямой урон картой | не больше 2                                                      | 1–2                                |

**Что стоит взять:** пул общих карт (например, 4 карты по 3 копии = 12) и сокращение геройских до 18 копий.
Это ускоряет выпуск новых героев, даёт игроку узнаваемый «общий язык» колод и упрощает баланс: половина
колоды у всех одинаковая. Названия, тексты и числа пишем свои.

## 2. Категории эффектов и покрытие движка

«Есть» — реализуется текущими правилами карты, без кода. «Частично» — нужен маленький экшен или факт.
«Нет» — нужна новая механика, добавлять только когда появится такая карта.

| Категория               | Что делает                                                | У нас    | Чем делается                                                        |
| ----------------------- | --------------------------------------------------------- | -------- | ------------------------------------------------------------------- |
| Урон и лечение          | снять/вернуть здоровье бойцу                              | есть     | `SET_HEALTH`                                                        |
| Добор и сброс           | взять, сбросить, переместить карты, в том числе случайные | есть     | `SET_CARDS`                                                         |
| Перемещение бойцов      | свои, чужие, на любое число клеток, черновик с бюджетом   | есть     | `SET_MOVEMENT` (умеет и врагов)                                     |
| Действия                | выдать дополнительное действие или отнять                 | есть     | `SET_ACTIONS`                                                       |
| Значение боя            | +N/−N или «значение становится X»                         | есть     | `SET_COMBAT { op: 'value', delta \| to }`                           |
| Отмена эффектов         | «отмените эффекты карты противника»                       | есть     | `SET_COMBAT { op: 'cancelEffects' }`                                |
| Условие «выиграл битву» | эффект только при победе или только при поражении         | есть     | факт `COMBAT { winner }`                                            |
| Доплата картой          | сбросить карту и прибавить её бонус к значению            | есть     | `SET_CARDS` + `SET_COMBAT value` (так работает одна из карт Теслы)  |
| Позиция как условие     | «если боец двигался», «если рядом», «если в области»      | есть     | `FIGHTERS { adjacentTo, areaOf, placed, alive }`, будущий `terrain` |
| Предметы и заряды       | счётчики и состояния копий (катушки, яд, пепел)           | есть     | `ITEMS`, `SET_ITEM`                                                 |
| Возврат бойца           | вернуть убитого помощника на клетку                       | есть     | `REVIVE_FIGHTER`                                                    |
| Раскрытие               | показать карты колоды всем, затем сбросить                | есть     | `SET_REVEAL`                                                        |
| Выбор варианта          | «выберите одно из», вариант может быть недоступен         | есть     | `SET_TARGETING { kind: 'options' }` + `options[].when`              |
| Подглядывание           | посмотреть руку или верх колоды противника                | частично | своя рука — факт `HAND`; чужая — нужен новый факт                   |
| Запрет защиты           | защитник не может положить карту                          | частично | нужен флаг в `SET_COMBAT`                                           |
| Игнор значений          | «урон не может быть уменьшен», «защита не считается»      | частично | тот же флаг боя                                                     |
| Появление бойца         | выставить нового бойца посреди партии                     | нет      | нужен экшен «поставить из `lost`»                                   |
| Объекты на клетках      | ловушка, метка, туман на клетке                           | нет      | нужны объекты состояния с координатой                               |
| Копирование и обмен     | сыграть чужую карту, обменяться руками                    | нет      | отдельные экшены, пока не нужны                                     |

## 3. Комбинации, которые стоит использовать

1. **Значение + условие.** Карта слабая по умолчанию и сильная при выполнении условия (позиция, местность,
   число живых помощников). Это наш основной приём: «+1 за каждого духа на лаве».
2. **Подготовка через перемещение.** Карта двигает цель или своих бойцов так, чтобы следующая карта стала
   сильнее. У нас уже есть принудительное перемещение врагов — это самый недоиспользованный рычаг.
3. **Цена здоровьем.** Сила за собственный урон: игрок сам решает, сколько темпа обменять на урон.
4. **Помощники как ресурс.** Живые помощники дают бонусы, мёртвые — открывают другие эффекты. Тогда
   «пожертвовать помощником» всегда размен, а не бесплатное ускорение.
5. **Бой как источник карт.** «Выиграл битву — возьми карту» создаёт цикл: атака → карты → атака. У нас
   есть и факт победителя, и добор.
6. **Отмена как страховка.** Карта, снимающая эффекты противника, обесценивает сложные комбинации — это
   здоровая защита от «снежного кома», но её должно быть немного (2–3 копии на колоду).
7. **Схема против боя.** Часть карт работает вне битвы (эффекты): перемещение, добор, местность. Без них
   колода становится предсказуемой.

## 4. Лимиты, которые стоит держать

- Значения: атака до 6, защита до 4 у героя. Прямой урон эффектом — не больше 2 за карту.
- Условий на карте — не больше одного, иначе игрок не считает, а читает.
- Террейновых карт на героя — 2–4: больше превращает партию в бухгалтерию.
- Много копий — только у «хлеба» (3 копии): сильные карты идут по 1–2 копии, иначе колода вырождается.
- У каждого помощника — минимум 2–3 карты, иначе помощник не ощущается.

## 5. Наблюдения по референсу (`.refs`, вне репозитория)

Папка `.refs` — личный референс: сканы карт для разбора приёмов. В `.gitignore` она уже есть, и правило
простое: **из неё в контент не переносится ничего** — ни тексты, ни названия, ни числа. Только категории
возможностей, которые ниже сформулированы нашими словами.

Что уже видно по двум разобранным героям (панель героя + карты):

| Приём из референса                  | Что это                                                   | У нас                                                                                          |
| ----------------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Усиление атаки второй картой        | при атаке можно положить вторую карту и прибавить её силу | частично: доплата картой у нас есть у Теслы, но как отдельный приём «положи карту рядом» — нет |
| Отмена эффектов гасит и усиление    | если эффекты карты отменены, сгорает и вложенная карта    | есть: `cancelEffects` отменяет эффекты стороны целиком                                         |
| Выбор нескольких эффектов из набора | «выберите 2 разных эффекта из 3»                          | **нет**: наше окно выбора работает только на одну цель (`count: 1`)                            |
| Телепорт бойца в любое место        | «поместите бойца в любое другое место»                    | **нет**: перемещение — черновик по радиусу, свободная постановка только на расстановке         |
| Лечение и добор на карте            | «восстановите 3 здоровья», «возьмите 2 карты»             | есть: `SET_HEALTH`, `SET_CARDS`                                                                |
| Большая карта без свойств           | значение 6 при пустом поле эффекта                        | есть: значение без правил — валидная карта                                                     |
| Герой с одной большой картой        | один сильный удар и слабая остальная колода               | это урок баланса: одна большая карта не делает героя, колоде нужен «хлеб» по 3 копии           |

Отсюда два кандидата в пробелы движка (в дополнение к разделу 2): **мультивыбор эффектов** и **свободная
постановка бойца (телепорт)**. Добавлять — только когда появится карта, которой это нужно.

## 6. Категории, досмотренные позже (16 героев)

Полный разбор героев — в `docs/reference-heroes.md`. Ниже — только категории эффектов, которые добавились
после второго прохода:

| Категория                                                | Что это                                                           | У нас                                                                   |
| -------------------------------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Ресурс-счётчик героя (ярость, заряды)                    | жетон, который растёт от событий и оплачивает тексты карт         | частично: `ITEMS` умеет состояния и количества, но счётчика у героя нет |
| Счётчик, растущий от полученного урона                   | «боль как топливо»: агрессор сам разгоняет защитника              | нет: нужен перехват события «герой получил урон»                        |
| Условие на размер руки («ровно 3 карты»)                 | сила за точное состояние руки, а не за «не меньше N»              | частично: факт `HAND` есть, условия «ровно N» нет                       |
| Счётчик действий в ходу («это третье действие»)          | один крючок награждает несколько карт сразу                       | нет: нужно считать действия в ходу                                      |
| Карта-продолжение, наследующая значение карты противника | после боя бьёт отдельной атакой со значением чужой карты          | нет: нужен доступ к значению сыгранной карты противника                 |
| Зеркальная защита («моё значение = значение его карты»)  | оборона, сила которой зависит от чужой карты                      | нет: тот же доступ к чужому значению                                    |
| Сравнение значений после боя («совпало — награда»)       | читаемая «угадайка» с наградой                                    | нет: нужно сравнить значения обеих карт после боя                       |
| Отмена эффектов вместе с игнорированием значения         | второй уровень контр-игры: мало отменить эффект, надо ещё и число | частично: `cancelEffects` отменяет эффекты, значение остаётся           |
| Перенаправление урона на своего другого бойца            | «зона безопасности» без объектов на карте                         | нет: нужен флаг боя «урон идёт другому бойцу»                           |
| Призыв нового бойца посреди партии                       | токены-копии, которые появляются по ходу игры                     | нет: нужен экшен «поставить бойца из `lost`»                            |
| Значки карт как условие («символ совпал с предметом»)    | включение эффекта через тег карты                                 | нет: нужен тег на карте и проверка совпадения                           |
| Предмет-джокер вне колоды                                | «считается за любой символ», открывает эффекты                    | частично: `ITEMS` есть, «джокера» нет                                   |
| Рециклинг ограниченного набора карт из сброса            | возврат конкретных карт вместо добора                             | есть: `SET_CARDS` умеет вернуть карту из сброса в руку                  |
| Переменная оплата ресурсом                               | «потрать сколько хочешь» — размер эффекта выбирает игрок          | нет: нужен эффект с ценой-переменной                                    |
| Обмен местами с помощником или героем                    | тактический выход из окружения                                    | нет: нужен экшен обмена                                                 |
| Защита с ±1 к значению во время боя                      | микрорешение прямо в бою                                          | нет: нужен выбор «+1 или −1» внутри боя                                 |

## 7. Области (стихии) как параметр карты

Отдельная категория при проектировании: **область** — то, что в референсе называется «зоной». У нас область
это стихия клетки: у клетки ровно один тип местности, он же её цвет (палитра — в `docs/terrain.md`).
Отдельного слоя владения или «зон расстановки» цветом у нас нет: расстановка идёт по списку стартовых
клеток, объявленному картой или генератором.

В разобранных наборах на область ссылаются одиннадцать героев из восемнадцати, причём и универсальные тоже
(подробности — в `docs/reference-heroes.md`, раздел 7). Референс отвечает через область на вопрос «где»,
и у нас на этот вопрос отвечает стихия.

| Что должна уметь карта                           | Наше состояние                                                                 |
| ------------------------------------------------ | ------------------------------------------------------------------------------ |
| «Бойцы в области героя»                          | есть: `FIGHTERS { areaOf: '<боец>' }` — стихия того, кого указали              |
| «Бойцы в области героя противника»               | нужно: параметр должен принимать роль (`own` / `enemy`), а не только id бойца  |
| «Бойцы в другой области» (не там, где я)         | нужно: условие «стихия клетки не совпадает с моей»                             |
| «Клетки такой-то стихии»                         | есть: `CELLS { terrain: 'swamp' }` и `FIGHTERS { terrain: 'lava' }`            |
| «Сколько областей занято врагами»                | нужно: факт по стихиям, где стоят враги (для карт, растущих от числа областей) |
| «Поставить или вернуть бойца в заданную область» | нужно вместе с телепортом: постановка в клетку нужной стихии                   |
| Стихии клетки                                    | есть: `node.terrain`; у клетки на стыке зон их две-три                         |
| Расстановка по области героя                     | есть: `startAreaCellIds` — клетки с общей стихией у номерной                   |
| Поле, собранное по сиду                          | есть: `generateMap` (28–38 клеток, 6–8 зон, симметричные старты)               |

Формулировка для текстов карт (предложение): **«область героя»** — стихии той клетки, где герой стоит сейчас;
**«в другой области»** — стихий, общих с его клеткой, нет. Стартовая область как понятие не нужна: старт —
это номерная клетка, поэтому в текстах пишем «на номерной клетке». В карте всегда указано, что имеется
в виду — стихия или конкретная клетка, иначе игрок не сможет посчитать эффект.

## 8. Чего в этом справочнике нет и не будет

Текстов карт, их названий, флавора и точных значений из чужих колод — это охраняемая форма. Берём только
категории возможностей и структурные ориентиры; всё, что попадает в наш контент, формулируется и нумеруется
нами (см. также раздел «IP: что своё, что чужое» в `TODO`).
