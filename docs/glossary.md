# Словарь проекта

Единый язык для текстов карт, документов и кода: одно понятие — одно слово. Тексты карт пишутся
только словами из этого словаря; если для новой механики нужного слова нет — сначала добавляем его
сюда, потом пишем текст. В колонке «В коде» — имя сущности, если она уже есть. Синонимы, указанные
в словаре, равноправны: где написано «синонимы», в текстах годится любой из них.

Термины, которых у нас **нет** и которые мы не заводим без нужды, помечены «нет»: это слова из
оригинала, ими описываем чужой разбор, но в наших текстах не пользуемся.

## 1. Партия и ход

| Термин             | Что значит                                                                    | В оригинале   | В коде                                            |
| ------------------ | ----------------------------------------------------------------------------- | ------------- | ------------------------------------------------- |
| **партия**         | одна игра от расстановки до победы                                            | game          | `state`, `createGame`                             |
| **ход**            | очередь одного игрока: начало хода → действия → конец хода                    | turn          | `turn`, хуки `turnStart` / `turnEnd`              |
| **действие**       | единица темпа хода: по умолчанию их два за ход                                | action        | `rules.actionsPerTurn`, `SET_ACTIONS`             |
| **активный игрок** | тот, чей сейчас ход                                                           | active player | `ACTIVE_PLAYER`, `state.turn.playerId`            |
| **место**          | позиция игрока за столом (1 — слева, 2 — справа, 3 — сверху, 4 — снизу)       | seat          | `shared/constants/seats.js`                       |
| **фаза**           | шаг внутри хода: лимит руки → выбор → перемещение → атака → защита → ожидание | phase         | `shared/phases/`, `state.hook`                    |
| **лимит руки**     | рука сверх предела: карты сбрасываются в конце хода                           | hand limit    | `HAND_OVER_LIMIT`, `rules.maxHandSize`            |
| **истощение**      | урон герою за карту, которой не нашлось в колоде                              | exhaustion    | `rules.exhaustionDamage`                          |
| **сдача**          | игрок прекращает партию                                                       | resign        | `RESIGN`, `SET_RESIGNED`                          |
| **сид**            | число, из которого детерминированно рождается вся случайность партии          | seed          | `state.settings.seed`, `shared/helpers/random.js` |
| **хотсит**         | режим, где за одним экраном играют оба игрока                                 | hotseat       | `app/composables/useGameSession.js`               |

| --------------------- | --------------------------------------------------------------------------- | ----------- | ----------------------------------------- |

| **помощник**          | вторая фигурка героя; может быть один или несколько                         | sidekick    | `fighter.type: 'assistant'`, `assistants` |

| **здоровье**          | сколько урона боец выдерживает; у героя оно больше, чем у помощника         | health      | `currentHp`, `startHp`                    |

| **убитый боец**       | боец со нулевым здоровьем уходит с поля. В текстах пишем «убит»             | defeated    | `player.lost`, факт `LOST`                |
| **возврат в игру**    | убитый помощник снова выставляется на поле                                  | resurrect   | `REVIVE_FIGHTER`                          |

## 7. Правила и движок

| Термин                         | Что значит                                                                                 | В коде                                                                                                                                                                  |
| ------------------------------ | ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **правило**                    | запись «момент + условие + действие»; из правил состоят карты, умения и предметы           | `rules: [{ moment, when, any, then }]`                                                                                                                                  |
| **факт**                       | чистая проверка состояния: даёт «да/нет» и значение, которое можно сохранить               | `FIGHTERS`, `HAND`, `COMBAT`, `CELLS`, `ITEMS`, `LOST`, `PICKED`, `AP`, `PLAYERS`, `REVEALED` и другие из `shared/facts/registry.js`                                    |
| **экшен**                      | универсальное изменение состояния; карты и умения собираются только из экшенов             | `SET_FIGHTER_CELL`, `SET_ACTIONS`, `SET_RESIGNED`, `SET_CARDS`, `SET_HEALTH`, `SET_MOVEMENT`, `SET_COMBAT`, `SET_TARGETING`, `REVIVE_FIGHTER`, `SET_ITEM`, `SET_REVEAL` |
| **клик игрока**                | то, что приходит с клиента: выбор цели или кнопка интерфейса                               | `PICK`, `UI_OK`, `UI_BACK`, `RESIGN`                                                                                                                                    |
| **условие**                    | список фактов внутри правила: `when` — «и», `any` — ветки «или»                            | `when`, `any`                                                                                                                                                           |
| **переменная**                 | результат факта, подставленный дальше по правилу как `$имя`                                | `var`, `resolveVars`                                                                                                                                                    |
| **автовыбор**                  | если кандидат один, движок отмечает его сам, окна игрок не видит                           | `SET_TARGETING { auto: true }`                                                                                                                                          |
| **максимальная автоматизация** | правило игры: безальтернативное решение делает движок — лишних кликов и подтверждений нет  | автовыбор, `auto: true`                                                                                                                                                 |
| **состояние партии**           | весь мир партии: поле, игроки, бойцы, карты, текущий ход                                   | `state`, `server/party.js`                                                                                                                                              |
| **проекция**                   | то, что видит конкретный игрок: чужое скрыто                                               | `view(state, playerId)`, `stateFields`                                                                                                                                  |
| **хук**                        | верхний уровень жизненного цикла: старт партии, начало хода, ход, конец хода, конец партии | `gameStart`, `turnStart`, `turn`, `turnEnd`, `gameEnd`                                                                                                                  |
| **момент**                     | точка внутри хода или битвы, к которой привязаны правила                                   | `gameStart`, `turnStart`, `effect`, `picked`, `immediately`, `duringCombat`, `afterCombat`, `turnEnd`                                                                   |

## 8. Дизайн героя

| Термин                   | Что значит                                                                                      |
| ------------------------ | ----------------------------------------------------------------------------------------------- |
| **архетип**              | кто герой по функции: трикстер, танк, контролёр, разгон, режим — из источника, а не из головы   |
| **сигнатурная механика** | одна главная механика героя, за которую его берут в руки                                        |
| **личное умение**        | hero skill: постоянная способность героя, отдельная от карт; в текстах «умение»                 |
| **пассивка**             | умение без выбора игрока: срабатывает само                                                      |
| **режим / форма**        | состояние героя, которое читают карты (стойка, облик, размер, гаджет). В движке пока нет        |
| **ось колоды**           | чем герой выигрывает: значением, позицией, темпом, контролем, ресурсом; осей не больше двух     |
| **цикл партии**          | идеальный ход героя по шагам                                                                    |
| **план А / план Б**      | как герой играет, когда всё хорошо, и что делает после потери помощника или руки                |
| **цепочка**              | связка «карта А → карта Б → карта В», которую игрок собирает в руке                             |
| **уязвимость**           | за что герой платит: цена, узкое условие, риск                                                  |
| **паспорт героя**        | файл `server/content/heroes/<id>/passport.md`: исследование источника и дизайн по семи разделам |
| **ростер**               | состав героев сезона и глав                                                                     |
| **сезон / глава**        | сезон — набор героев и сюжетная линия, глава — одна его часть                                   |
| **кроссовер**            | правило мира: герои из разных источников встречаются на одной арене                             |
| **сцена**                | единица кампании: расстановка, цель, герои, награда                                             |

| **есть / частично / нет** | вердикт «собирается ли механика нашим движком»: текущими средствами, с доработкой, никак |

## 10. Права и источники

| Термин                          | Что значит                                                                          |
| ------------------------------- | ----------------------------------------------------------------------------------- |
| **общественное достояние (PD)** | произведение, у которого истекли права (Баум, Андерсен, мифы); можно брать свободно |
| **охраняемая форма**            | имена, тексты, флвор и точные числа чужого набора; не переносим                     |
| **пересказ механики**           | мы берём приём и описываем его своими словами                                       |
| **атрибуция**                   | указание источника свободной картинки; для текстур стихий записано в шапках пекарей |

## 11. Как говорим и как не говорим

| Не говорим         | Говорим                  | Почему                                                                              |
| ------------------ | ------------------------ | ----------------------------------------------------------------------------------- |
| зона               | **область**              | у нас область = стихия клетки; «зона» тянет за собой чужую терминологию             |
| бой                | **битва**                | договорились в текстах карт и документах                                            |
| юнит, фигурка, чип | **боец**                 | в текстах карт только «боец»; «фишка» — про отрисовку                               |
| сайдкик            | **помощник**             | своё слово вместо чужого                                                            |
| скилл              | **личное умение**        | в документах «умение»                                                               |
| тайл, ячейка       | **клетка**               |                                                                                     |
| сила карты         | **значение карты**       | «сила» размыто: есть сила героя как понятие дизайна                                 |
| повержен           | **убит**                 | в наших текстах «убитый боец»; «повержен» и «выбывший» — слова из разбора оригинала |
| сброс карты        | **сбросить карту**       | «сброс» — зона, действие — глагол                                                   |
| мёртвая карта      | **карта без применения** | «мёртвая» — жаргон                                                                  |
