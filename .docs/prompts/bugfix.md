# Багфикс

```
Симптом: [что видно: игрок не может ..., окно не закрывается, партия падает — одно предложение]

Воспроизведение:
  1. node bot/tools/hotseat.js --seed=[N] --players=4     # одна находка по сиду
  2. [что нажать или какое действие — если не через бота]
  3. [что происходит; текст ошибки — целиком]

Ожидаемо: [что должно происходить]

Где подозреваю: [shared/actions/..., app/composables/..., server/... — если известно]
Не сломать: [что рядом работает: соседние действия, та же карта у другого героя]

Критерий готовности: тест падает до фикса и зеленеет после
  node node_modules\vitest\vitest.mjs run tests/unit/[путь].test.js --pool=threads
```

Партия воспроизводится по сиду: `node bot/tools/hotseat.js --seed=N --players=4` — разбор одной находки,
`node bot/tools/run.js --seeds=N` — фаззинг пары героев. Лог действий из отчёта приложить к карточке.

- Тест нужен, если баг в логике. Баг только в вёрстке тестом не закрепляем: её смотрит владелец глазами.
- От агента: причина (а не «поправил»), минимальный дифф, прогон сломанного сценария, отчёт
  «что изменено / что запущено / что не проверено».
- Похожее уже ломалось — свериться с `.docs/pitfalls.md`, прежде чем искать причину заново.
