# 0002. Меняемые числа — только в `tuning.js`

- **Дата:** 2026-11-17
- **Статус:** принято

## Контекст

Таймауты, правила партии, лимиты и длительности анимаций правились по разным файлам: владелец и агент
искали числа по коду и находили не все. Карты «где какое число» не было.

## Решение

Числа, которые может захотеть поменять владелец, живут в `shared/constants/tuning.js`: `TIMEOUTS`, `RULES`,
`LIMITS`, `ANIMATION_DURATIONS`, `BOARD`. `shared/constants/rules.js` собирает `rules` из `RULES`;
`app/constants/animation.js` ре-экспортирует `ANIMATION_DURATIONS` и добавляет множитель скорости.

## Следствия

- Новое число — в `tuning.js`; тот же литерал в другом файле — дефект.
- Значения `BOARD` не дублируются: `tests/unit/content/generator.test.js` берёт их оттуда же.
- Потребители: `server/validations.js`, `server/party.js`, `shared/helpers/mapGenerator.js`,
  `app/composables/ui/useClock.js`, `app/composables/game/useGameAi.js`.
- Смысловые данные (герои, карты, стихии) здесь не живут: это контент, а не настройка.

## Альтернативы

- **Число рядом с использованием.** Отклонено: искать по всем файлам, правка баланса задевает код.
- **Свой конфиг на игру, UI и бота.** Отклонено: три места вместо одного, синхронизация руками.
