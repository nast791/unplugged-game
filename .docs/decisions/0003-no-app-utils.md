# 0003. Папки `app/utils/` нет

- **Дата:** 2026-11-17
- **Статус:** принято

## Контекст

Nuxt сканирует и `app/utils/`, и `app/composables/`. Две папки под клиентскую логику дают два ответа на
вопрос «куда положить функцию», а автоимпорт прячет зависимость: по файлу не видно, откуда взята функция.

## Решение

Клиентская логика — только в `app/composables/` по папкам: `game/` (партия), `ui/` (интерфейс),
`animations/` (движение), `api/` (запросы). Композабл импортируется явно:
`import { useBoardMap } from '~/composables/ui/useBoardMap.js'`. Константы клиента — только `app/constants/`.

## Следствия

- Новый файл кладётся в одну из четырёх папок; корень `app/composables/` и `app/utils/` не заводим. Список и
  правила раскладки — `.docs/rules/architecture.mdc`.
- Константу в `<script setup>` не заводим: только `app/constants/` или `computed`.
- Тесты берут композаблы по явному пути: `tests/unit/client/board-map.test.js`, `tests/unit/client/cn.test.js`.

## Альтернативы

- **`app/utils/` для мелких функций.** Отклонено: второе место для той же логики.
- **Полагаться на автоимпорт Nuxt.** Отклонено: `pnpm dev`, поднятый до появления файла, падает в рантайме
  (`useProfile is not defined`), а сборка остаётся зелёной.
