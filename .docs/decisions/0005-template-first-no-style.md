# 0005. Сначала `<template>`, `<style>` не используется

- **Дата:** 2026-11-17
- **Статус:** принято

## Контекст

Стили жили и в `<style scoped>`, и в классах разметки — вид одного элемента искали в двух местах. Порядок
блоков был вольным, поэтому чтение `.vue` начиналось с логики, а не с вида.

## Решение

В `.vue` первым идёт `<template>`, вторым `<script setup>`; блока `<style>` нет вообще. Вид — классами в
разметке, повторяющийся набор — пресетом из `app/ui/` (`button.js`, `modal.js`, `hexagon.js`) через `cn`
(`app/ui/cn.js`). В `<template>` комментариев нет, в `<script>`/`.js` — короткое `//` о неочевидном, без JSDoc.

## Следствия

- Цвета и отступы ищутся в разметке; пресет — когда набор классов повторяется (границы —
  `.docs/rules/code-style.mdc`, вёрстка — `.docs/ui.md`).
- `cn` не принимает `w-*`/`h-*` вместе с `size-*`: конфликт ловит `tests/unit/client/cn.test.js`.
- Вёрстку и стили агент не проверяет — их смотрит владелец глазами (`.docs/workflow.md`).

## Альтернативы

- **`<style scoped>`.** Отклонено: вид в двух местах, `scoped` не работает для дочерних компонентов.
- **JSDoc и шапка-описание в `.vue`.** Отклонено: файл читается под задачу, объяснение — в композабле.
