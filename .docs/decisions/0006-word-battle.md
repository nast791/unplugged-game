# 0006. В текстах для игрока «битва», а не «бой»

- **Дата:** 2026-11-17
- **Статус:** принято

## Контекст

Одно событие называлось в картах, подсказках и панелях и «боем», и «битвой». Игрок видел два термина для
одного действия, а поиск по текстам давал несопоставимые списки.

## Решение

В текстах для игрока — только «битва», «бой» не пишем ни в каком падеже; «боец/бойцы» остаются. Префикс
момента один — `ПОСЛЕ БИТВЫ` в `CARD_MOMENT_PREFIXES` (`app/constants/cards.js`). Остальные ключи:
`МГНОВЕННО`, `ВО ВРЕМЯ БИТВЫ`, `НАЧАЛО ХОДА`, `КОНЕЦ ХОДА`.

## Следствия

- Тексты карт — в `server/content/`, подсказки — в `shared/constants/hints.js`; новый текст сверяют с этим ADR.
- `tests/unit/cards/text-paraphrase.test.js` ловит `бо(й|ю|я)` регуляркой и пропускает «боец».
- `tests/unit/client/card-text.test.js` держит префиксы: `momentOfPrefix`, `cardTextParts`.

## Альтернативы

- **Оставить оба слова синонимами.** Отклонено: синоним в интерфейсе = второй термин в глоссарии.
- **Переименовать «бойца» в «воина».** Отклонено: термин закреплён в правилах и референсах.
