# 0004. Компоненты импортируются явно

- **Дата:** 2026-11-17
- **Статус:** принято

## Контекст

Автоимпорт компонентов прячет происхождение тега: в разметке `AButton`, а где его файл — неизвестно.
Переименование ломает разметку молча, поиск по имени даёт только шаблоны.

## Решение

В `nuxt.config.ts` стоит `components: []` — автоимпорта компонентов нет. Каждый импортируется явно:
`import AButton from '~/components/atoms/AButton.vue'`. Nuxt даёт сам `NuxtLink`, `ClientOnly`, `NuxtPage`;
`Icon` — из `@nuxt/icon`, `v-stage` — из `vue-konva` через `app/plugins/konva.client.js`.

## Следствия

- Новый компонент — строка импорта в том файле, где он нужен, путём от `~`.
- Свой компонент без импорта не заработает; глобальные теги — только из списка выше.
- Имя компонента = имя файла; конвенции — `.docs/rules/code-style.mdc`, вёрстка — `.docs/ui.md`.
- Отдельных проверок нет: сломанный импорт виден сразу — страница не отрисуется.

## Альтернативы

- **Включить автоимпорт по `dirs`.** Отклонено: скрытые зависимости и два правила вместо одного.
- **Глобальная регистрация плагином.** Отклонено: тот же скрытый источник имени, плюс порядок загрузки.
